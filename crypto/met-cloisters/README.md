## Walkthrough

This is a scytale, a ancient cipher where a message is decoded by wrapping the strip around a specially-sized rod. This one can be decoded by aligning the start of the markings on one side with the start of the other. The combined markings are Cistercian numerals that represent ASCII character code points of "SellTheExtraBeer"

## Flag

`pdx{SellTheExtraBeer}`
